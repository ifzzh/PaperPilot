# PaperPilot v0.10.3

PaperPilot v0.10.3 fixes the Daily arXiv PDF and cover pipeline. Metadata ranking and LLM enrichment now finish before asset work begins. A persistent, global single-flight coordinator downloads and validates one PDF at a time, rotates between users, restores interrupted leases after restart, and prevents duplicate work for the same user and arXiv ID.

Document Worker jobs are now cancelled or released before their staging directory is removed. Terminal jobs no longer occupy the Worker queue indefinitely, one corrupt job cannot stop its dispatcher, and `/healthz` reports only non-sensitive `busy` and `queued` counts.

Daily arXiv cards display `等待下载`, `正在下载`, `安全验证中`, `等待重试`, `PDF 已就绪`, or `处理失败`, plus queue position and the stable error code when applicable. The page refreshes active assets automatically so PDF first-page covers appear without a manual reload.

## Retry behavior

- HTTP, malformed PDF, and parser failures count toward the five-attempt limit and use 5-minute, 30-minute, 2-hour, and 6-hour backoff.
- `document_queue_full`, a temporarily unavailable Worker, staging unavailability, and interrupted Web work do not consume an attempt; they retry after 60 seconds.
- Asset retries never rerun Daily arXiv summary, keyword, or ranking LLM calls.
- A manual retry is idempotent. A ready asset returns `409 asset_already_ready`.

## Upgrade from v0.10.2

Keep v0.10.2 running while testing on a copy. Before the formal upgrade, back up SQLite and the paper directory, then stop all three services and run:

```bash
python -m paperpilot.migrations.v0103_daily_assets \
  --db /path/to/paperpilot.db --dry-run

python -m paperpilot.migrations.v0103_daily_assets \
  --db /path/to/paperpilot.db --apply --backup-dir /path/to/backups
```

The migration uses SQLite Backup API, preserves the live database inode, ownership and mode, adds the asset lease/error fields, and requeues `candidate`, `queued`, `downloading`, `validating`, and `retry_wait` rows. Metadata, topic reasons, retry counts, Reading List data, translations and existing PDFs are preserved.

Deploy the Web, translation-worker and document-worker v0.10.3 digests together. The only host binding remains `127.0.0.1:7191:7191`; ports 7192 and 7193 remain private.

Rollback while services are stopped:

```bash
python -m paperpilot.migrations.v0103_daily_assets \
  --db /path/to/paperpilot.db --rollback /path/to/paperpilot-v0.10.3-*.manifest.json
```

Then restore all three v0.10.2 image digests. This release does not change Daily arXiv topics, the 12/8/4 quotas, the 24-paper daily maximum, seven-release-day retention, authentication, translation results, or paper storage layout.
