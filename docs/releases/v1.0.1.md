# PaperPilot 1.0.1 — cold-start library fix

After restarting Web, opening `/workbench` directly could show an empty or incomplete library until legacy category/Reading List requests populated the cache. The all-papers endpoint now loads the current owner's existing category and Reading List assets itself. Direct detail/file lookups also load on cache misses. A single upsert or move no longer marks a whole category as scanned; completeness is recorded after scanning finishes.

Regression fixtures retain metadata and synthetic PDFs while discarding the process cache. They cover populated and empty accounts, root/subcategory/Reading List assets, partial caches, direct detail/file access, repeated restarts and cross-owner rejection. No production database is copied and no model or parsing task is launched.

Only Web advances to 1.0.1.
