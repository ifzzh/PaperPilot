# PaperPilot 1.1.3 — 统一文献库与阅读问答

本版本将首页、文献库、连续 PDF 阅读、侧栏问答、Daily arXiv、任务、设置与账号流程整合为同一个应用。历史 `/workbench` 与 `/viewer` URL 兼容跳转；实验开关退役。运维回退使用镜像与配置，产品不再提供版本切换入口。

> 1.1.0 在候选阶段发现导入契约遗漏，保留原 tag/版本镜像，不正式部署、不更新 latest；1.1.1 上线后发现稳定阅读位置问题并已回退，1.1.2保持未部署草稿，最终统一产品交付使用 1.1.3。

## 既有翻译任务补丁

任务中心将服务端 job_id 适配到统一任务标识，展示已有任务与终态日志；按类型及标识去重，只为服务端可重试的失败状态提供重试。新增真实Flask持久任务用例，避免空任务列表掩盖契约遗漏。

## 阅读位置补丁

占位页按照实际页面尺寸与当前缩放/旋转同步更新；加载、跳页、缩放、旋转及侧栏/窗口尺寸变化保持同一页内锚点，避免浏览器滚动锚定与应用恢复竞争。新增回归同时核对实际页面几何位置、稳定后的保存结果以及新会话恢复，不再只检查短暂页码或 HTTP 成功。

## 导入补丁

Zotero 提交使用 `target_category_id`，进度以既有 SSE 消费，元数据备份按归档分类恢复。导入任务状态、进度、取消按 owner 检查；后台执行使用有界队列并继承提交者身份。队列满时明确拒绝并清理 Worker 任务，不把别人的任务状态或编号暴露给当前用户。

## 主要变化

- 修复 Edge 139 上 PDF.js worker 使用未支持的 Map 方法导致原文、译文均无法打开的问题。匹配的 compatibility display/worker 与字体、CMap、WASM 资源同源自托管，不放宽脚本 CSP。
- 分类、列表、详情采用 PaperQuay 的布局与交互参照，保留 PaperPilot 品牌；支持浅深主题、移动面板、紧凑列表、搜索、收藏、Reading List、导入与元数据编辑。
- 阅读区填满剩余视口，支持论文标签、连续页、缩略图、页码、缩放、旋转、文档切换与文本选择。渲染按可见范围加载，非活动文档销毁 worker 和 canvas。
- 阅读位置分用户、论文、原文/译文保存；刷新与重新登录恢复。指纹变化重置无效位置；读取位置失败不会覆盖原记录。
- 侧栏提供历史、多会话、流式回答与确认后的选区问题。沿用首行会话 JSON + 原始文本协议；停止接收只停止浏览器读取，不宣称服务端取消。历史未确认保存时显式提示，不自动重发。
- Daily、上传/导入、任务进度/日志、翻译与分析、设置、账号和管理员操作在统一界面内完成，无旧页面嵌入。
- 分类根按 owner 虚拟化，保存采用单事务；不改变已有分类 ID、用户文件或数据库 schema。工作区和阅读位置写入现有 owner 设置存储，校验 CSRF、所有权、大小与数值范围。
- 外部静态 CSS，正式阻断 `style-src-attr 'none'`；分栏与 PDF 文本定位使用浏览器验证的 CSSOM 更新。

## 验证与边界

开发验收已实际打开 AutoSci 原文与已有中英对照 PDF，均 22 页；另两篇实际论文可读。生产论文截图与文本证据仅私有保存。合成数据覆盖百页阅读、原译文独立位置、三标签、加密/缺失/损坏文件、流异常和退出跨标签清理；完整 HTTP Document Worker 上传链路使用独立 staging 与已有 Worker 摘要。

一次受限真实选区问答在隔离 Flask 应用通过：最多 512 token、120 秒、SDK 无重试，共 1 次请求，回答保存、刷新与 owner 隔离通过。没有追加 MinerU 云任务、解析或翻译生产论文。高级 Agent、块级翻译、结构坐标持久化、笔记、RAG、综述和图谱继续分阶段实现，不提供占位入口。

客户端每页 50 条只减少 DOM，不减少现有 API 全量响应。性能记录为本机实测，不是跨设备时延承诺。PDF compatibility 模块带来较大按需加载包，构建仍报告约 500 kB chunk 提醒。

发布候选的完整 Docker、安全扫描、SBOM、远端摘要与正式部署结果在完成后补入本记录；此版本说明草稿不代表已发布。

## 回退原则

部署前保存一致性数据库备份、受限配置和实际组件摘要。仅更新 Web，Worker 仓库、摘要、端口和资产挂载不变。正式验收失败则恢复部署前 Web 1.0.1 摘要与配置，并恢复 `latest` 渠道。无 schema 迁移，不以备份覆盖部署后新增用户数据。具体备份路径与生产验收记录私有保存。
