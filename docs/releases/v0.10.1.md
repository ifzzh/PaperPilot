# PaperPilot v0.10.1

PaperPilot v0.10.1 is the required migration compatibility patch for v0.10.0.

The v0.10.0 offline workflow migration could fail on a real v0.9.1 database because it created the new translation queue index before adding the queue columns. Its recovery path also attempted to copy file ownership timestamps onto the container-owned Daily arXiv settings file. The database backup recovery succeeded, but deployment could not continue.

This patch adds translation columns before executing the additive schema, preserves the existing settings inode and ownership during apply, and restores settings content without changing ownership metadata. A regression fixture now starts from the exact legacy translation table shape.

All v0.10.0 application features remain unchanged. Installations upgrading from v0.9.1 must use the v0.10.1 migration tool and deploy all three v0.10.1 images. Do not deploy v0.10.0 directly. The v0.10.0 data migration is transactional and the failed attempt does not require manual cleanup when database and settings hashes match their backup.
