# PaperPilot v0.9.1

PaperPilot v0.9.1 is a compatibility and data-visibility patch for v0.9.0.

## Fixes

- Restores Reading List papers after tenant migration by scanning the current user's `_ReadingListTemp` directory and keeping the scan cache isolated per owner.
- Lowers the password minimum from 12 characters to 8 for registration, password changes, bootstrap credentials, and reset credentials. Argon2id hashing parameters are unchanged.
- Adds an explicit RFC 2544 fake-IP DNS compatibility setting for transparent proxies. It is restricted to administrator-approved public HTTPS hostnames and never permits IP literals, localhost, RFC1918 LANs, link-local addresses, or cloud metadata targets.

## Deployment

There is no database or storage migration. Deploy all three v0.9.1 images together. Installations whose resolver returns `198.18.0.0/15` for public AI services must set:

```dotenv
PAPERPILOT_AI_PROXY_FAKE_IP_RANGES=198.18.0.0/15
```

The maintained Compose file continues to expose only `127.0.0.1:7191`.
