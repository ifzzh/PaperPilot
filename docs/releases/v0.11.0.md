# PaperPilot v0.11.0

PaperPilot v0.11.0 closes the remaining script-execution security debt in the Web frontend.

Marked 15.0.12, Highlight.js 11.9.0, MathJax 3.2.2, Font Awesome 6.0.0 and DOMPurify 3.4.14 are now served exclusively from `/static/vendor`. The repository records every vendor file's version, source, license and SHA-256 digest in `static/vendor/manifest.json`. Browser-side PDF.js code was removed because untrusted PDF inspection belongs only to the isolated Document Worker.

All template scripts are external files. Static and generated controls use fixed `data-action` values with delegated event listeners instead of inline event attributes. The enforced Content Security Policy allows scripts only from the application origin and rejects script attributes, plugins, external frames and unexpected network connections. Markdown remains Marked → DOMPurify → DOM post-processing, so tables, code highlighting and MathJax formulas keep their existing presentation.

The policy intentionally retains `style-src 'self' 'unsafe-inline'` for v0.11.0. Removing roughly 250 inline style declarations without a visual regression is tracked separately for v0.11.1. No `unsafe-eval`, script nonce, script hash or external script origin is permitted.
