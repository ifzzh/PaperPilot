# PaperPilot v0.10.2

PaperPilot v0.10.2 is the final deployment patch for the v0.10 workflow release.

It preserves the existing SQLite and Daily arXiv settings file inode, ownership and mode when a migration is rolled back or an apply operation fails. This prevents the non-root Web container from losing group write access after recovery.

The patch also completes the default simplified-Chinese experience by translating the login subtitle and first-run onboarding content directly in the shipped template. `Daily arXiv`, `Reading List`, PDF, LLM, MinerU, BabelDOC and Markdown remain unchanged product or technical names.

All durable translation tasks, personalized Daily arXiv topics, cover generation, ISO dates and self-service password changes introduced in v0.10.0 remain unchanged. Deploy all three v0.10.2 images together. Installations still on v0.9.1 should skip v0.10.0 and v0.10.1 and upgrade directly to v0.10.2.
