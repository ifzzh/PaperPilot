# iPaper 1.1.4 — 品牌与部署迁移

本版本将 PaperPilot 的当前产品标识统一为 iPaper，Python 包、命令和三个镜像仓库使用 ipaper，正式配置使用 IPAPER_。不新增 Agent、翻译等功能，不改变数据库 schema 或用户资产标识。

GitHub 已迁至 [ifzzh/iPaper](https://github.com/ifzzh/iPaper)。历史 Web 和 Worker 镜像按原 digest 复制到三个新仓库，历史版本不重建；本版本因包和启动入口变化重建三个组件。旧仓库、历史内容和上游署名保留。

新旧环境前缀兼容，IPAPER_ 优先；既有会话 Cookie、分类 namespace、密钥 AAD 和迁移标记保持稳定。迁移过程、显式持久卷绑定和回退原则见 [迁移指南](../operations/ipaper-migration.md)。

当前为候选记录。正式发布时补入最终摘要、历史镜像清单、全量测试/安全/SBOM与实际部署验收结果，不将本文件当成已部署证据。
